# Feature Backlog

## Round of Doublers

Complete. This generic manual feature is not tied only to a 60-point loss. The player chooses how many upcoming hands the round affects; the default uses the number of players currently in rotation, but remains editable. The current schedule can overlap through **Now** or append through **End**. It applies a minimum multiplier, persists per game, consumes one entry per submitted hand, and restores exact schedule state through Undo. History continues to use its normal effective multiplier badges (`2x`, `4x`, `8x`, and so on); no separate star indicator is used.
