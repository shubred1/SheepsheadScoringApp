# Feature Backlog

## Round of Doublers

Planned as a generic manual feature, not one tied only to a 60-point loss. The user chooses how many upcoming hands the round affects; the default may use the number of players currently in rotation, but remains editable.

If a round is already active, **Start Now** overlaps it and stacks multipliers, while **Add to End** appends the new round after it. Hand-specific multipliers also stack. The scoring screen should show active doublers and hands remaining. History should use the existing effective multiplier badges (`2x`, `4x`, `8x`, and so on); no separate star indicator is currently planned. The normal multiplier control remains the per-hand multiplier, with the doubler effect applied automatically.
